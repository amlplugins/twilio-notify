# @amlplugins/twilio-notify

Native `twilio` SDK re-exported under the `@amlplugins` namespace.

> Twilio Notify — cross-channel push notifications (APNs, FCM, SMS, Facebook Messenger).

## Install

```bash
npm install @amlplugins/twilio-notify
```

## Use

```ts
import { /* named exports from twilio */ } from "@amlplugins/twilio-notify";
// or
import sdk from "@amlplugins/twilio-notify";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
